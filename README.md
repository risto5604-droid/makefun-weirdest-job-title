One job title, 60 characters or fewer: a professional mourner — for retired office printers. A real-sounding job with one hilariously specific twist, written for the blind judge showdown.

## Run it

```sh
python3 main.py
```

`main.py` writes the title to `/output/entry.txt` (exactly the title, nothing else), guarded by a ≤60-character ASCII gate.
